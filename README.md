# ARCHIVE 27

### The Museum of Things We Almost Forgot

> **EVERYTHING DISAPPEARS. WE KEEP THE TRACE.**

ARCHIVE 27 is a fictional digital archive preserving objects, places, sounds, letters, photographs, and memories that are slowly disappearing from collective memory.

Designed as a digital museum rather than a conventional product website, the experience combines **European editorial design, contemporary museum aesthetics, archival storytelling, and subtle motion**.

---

## ✦ The Concept

ARCHIVE 27 explores a simple question:

**What remains after something disappears?**

Each object in the archive is presented as a record rather than a product. Visitors can explore its history, location, year, status, story, and archival notes.

The current collection contains **7 documented records from a larger archive of 27 objects**.

## ✦ Design Direction

The visual language combines:

* European editorial layouts
* Contemporary museum websites
* Archival photography
* Warm paper-like tones
* Serif editorial typography
* Minimal interface elements
* Subtle movement and interaction

The design intentionally avoids conventional e-commerce patterns such as product cards, pricing grids, excessive rounded UI, and generic dashboard layouts.

## ✦ Running Locally

Clone the repository:

```bash
git clone https://github.com/tanvishrivastava338-a11y/archive-27.git
```

Move into the project:

```bash
cd archive-27
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
